# Prepared mock tests

`index.js` lists the prepared mocks for each exam path. All built-in questions are original.

- `nsuEnglish.js`, `nsuReading.js`, `nsuEssay.js`: written by hand.
- `nsuQuant.js`: generated by `python3 scripts/gen-quant.py`. Every answer is computed from the numbers in the question.
- `extra.js`: add your own sets here, but only content you have the right to publish. Mnemoq does not ship third-party question books.

Each question: `{ id, question, options: [5 strings], answer: 0-4, topic, explain }`.
